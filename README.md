# ShopDesk – Training App

Frontend internship training project built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Getting Started

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

To create a production build:

```bash
npm run build
```
